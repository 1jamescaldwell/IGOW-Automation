I built a script that automatically loads the prize winners and sends a customized message for each prize. 

To run, the script needs a .exe file (to the right of this page, click "releases"), links.txt file, and a google email API authentication file. The API file takes ~10 minutes to set up, but once setup it allows the script to run locally on your computer so that I never need to access your email or password in any way.
